Installation Windows x64

Install the format your DAW supports

Close your audio host before installing. Extract the ZIP, then copy the plugin file or bundle to one of the standard locations below. The combined ZIP contains both formats; install only the formats your host supports.

VST3

Copy the full bundle

Copy the complete Pro-55.vst3 folder, including its Contents folder.

  • Per-user%LOCALAPPDATA%\Programs\Common\VST3
  • System-wideC:\Program Files\Common Files\VST3
CLAP

Copy the plugin file

Copy Pro-55.clap into the CLAP folder used by your audio host.

  • Per-user%LOCALAPPDATA%\Programs\Common\CLAP
  • System-wideC:\Program Files\Common Files\CLAP

Finish setup: Start or restart your audio host and rescan for plugins if needed. System-wide folders may require administrator permission; use the per-user folder to avoid that. Pro-55 is an unsigned beta, so Windows may show a security warning.
